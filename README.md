# Adarsh Kumar Jain’s engineering portfolio

Five static pages cover the overview, projects, experience, skills and contact details. Run `python -m http.server 8000` at the repository root and open http://localhost:8000 to preview. Deploy the repository root with no build step.

The pages share styles in `assets/css/styles.css` and navigation and project filter behavior in `assets/js/main.js`. Project illustrations and the portrait are in `assets/images/`. The résumé is in `assets/documents/`.
