# Adarsh Kumar Jain’s engineering portfolio

A responsive DevOps and platform engineering portfolio with professional experience, project walkthroughs, public code links and a downloadable résumé.

## Local preview

Run `python -m http.server 8000` from the repository root and open http://localhost:8000. No build or package installation is required.

## Updating the site

Edit `index.html` for career details and projects, `assets/css/styles.css` for presentation, and `assets/js/main.js` for the interactive stack illustration. Replace `assets/documents/Adarsh-Kumar-Jain-Resume.pdf` when the résumé changes.

The repository root is the publish directory for static hosting. Relative asset links also support GitHub Pages project URLs.
